# Portal PDI Universidad de Santander

Base inicial del portal en React + TypeScript para construir el seguimiento del PDI.

## Arranque

```bash
npm install
npm run dev
```

## Estructura inicial

- `src/components`: componentes reutilizables.
- `src/data`: datos base para la primera iteracion.
- `src/styles`: estilos globales y de la aplicacion.
- `src/types`: tipos de dominio.
